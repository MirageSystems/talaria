# Roadmap

## First release

- Codex-login-only authentication.
- Dynamic Codex model discovery from the local account.
- Claude Code `/model` integration.
- Offline tests for catalog parsing, Anthropic-compatible streaming, and tool calls.
- Minimal launcher and doctor commands.

## Explicit non-goals

- OpenAI API key mode.
- Anthropic passthrough.
- Generic OpenAI-compatible providers.
- Local model routing.
